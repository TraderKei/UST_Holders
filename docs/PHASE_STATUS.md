## 이번 단계에서 완료한 보조 분석 차트

- 국가별 증감 순위는 선택 증감 기준(1·3·6·12개월)과 금액 단위를 공유하고 증감액/증감률 전환, 증가·감소 Top 10, 0 중심 동일 선형 축, 선택 국가 강조, 전체화면 확대를 제공한다. 로그축은 사용하지 않는다.
- 국가별 점유율은 현재 필터 모집단에서 보유액 상위 10개 국가를 정렬하고, 항상 Grand Total을 분모로 계산한다. 기타는 `Grand Total − 표시 Top 10`으로 계산해 지역 합계를 중복하지 않으며, 반올림 전 합계 검증값 `100.000000%`를 화면에 표시한다.
- 점유율 행은 현재 순위와 전월 순위 변화(▲/▼/─, 비교 불가 시 N/A)를 표시하고 선택 국가를 강조한다.
- 장기채·단기채 구성은 선택 국가와 국가 검색·지역·그룹 필터를 반영한다. 총보유액, 장기채, 단기채, 각각의 비중, 전월 대비 장기채 비중 변화(pp)를 제공하며 결측값을 0으로 바꾸지 않는다.
- 100% 누적 가로 막대는 장기·단기 비중이 모두 있을 때만 렌더링하며, 툴팁과 상세 값에 `장기채 + 단기채 = 총보유액` 검증 결과를 표시한다.
- 보유잔액 변화 분해는 전월 보유액, 순매입·순매도, 장기채 평가변동, 기타 조정/잔차, 현재월 보유액을 표시한다. `2023-02` 이전 또는 필수 값 결측 시 `분해 불가 · N/A`를 표시한다.
- 워터폴은 음수 누적값도 포함하는 선형 축을 사용하며 시작·종료 일치 상태와 잔차 산식을 툴팁에 표시한다. 제목과 접근성 설명에 보유액 변화와 자금 흐름이 다른 개념임을 명시했다.
- 모든 보조 차트는 기존 기준월, 증감 기준, 금액 단위, 검색·지역·그룹·선택 국가 상태를 공유한다.

## 이번 단계에서 완료한 국가 비교 시계열

- 일본·중국·영국·한국·외국인 전체를 초기 비교 대상으로 유지하고 최대 5개 선택 제한을 표 체크박스와 비교 칩에 동일하게 적용했다.
- 국가 코드를 키로 사용하는 고정 색상, 범례 표시·숨김, 표 선택과 차트 선택의 양방향 상태 공유를 적용했다. 검색·지역·그룹 필터는 이미 선택한 차트 계열을 임의로 숨기지 않는다.
- 기준월을 끝점으로 1Y 12개월, 3Y 36개월, 5Y 60개월, 10Y 120개월, MAX 전체 기간을 정확히 계산하며 드래그 확대와 확대 초기화를 제공한다.
- 보유액·증감액·증감률·전체 대비 비중·순매입/순매도 표시 지표와 USD bn/USD mn 단위 변경을 값·축·툴팁에 함께 반영한다.
- 절대값과 선택 구간 시작월=100 지수를 전환한다. 시작월 값이 없거나 0이면 임의 기준값을 만들지 않고 N/A로 유지한다.
- 공통 십자선 툴팁에 기준월, 표시 값과 단위, 선택 증감 기준의 증감률, 원본 구간 상태, 잠정 플래그 상태를 표시한다. 범례에서 숨긴 국가는 툴팁에서도 제외한다.
- 결측 월 앞뒤를 별도 SVG 경로로 분리해 선으로 연결하지 않는다.
- `2020-01` Historical CSV → Table 3 연결 지점과 `2023-02` 순거래·평가변동 제공 시작 지점을 차트에 표시한다.
- `is_preliminary=true`인 확인된 구간만 점선으로 그리도록 했다. 현재 스냅샷은 플래그가 모두 `null`이므로 데이터 계열에 임의 점선을 표시하지 않는다.
- 절대값에서 Grand Total과 개별 국가를 함께 선택하면 Grand Total을 우측 보조축으로 분리한다. 증감처럼 음수가 가능한 지표도 좌·우 축 범위를 각각 계산한다.

## 공식 원본과 manifest

공식 HTML을 크롤링하지 않고 다음 TXT/CSV만 사용했다. 다운로드한 바이트를 수정하지 않고 `data/raw`에 저장했다.

| 파일 | 다운로드 시각 (UTC) | SHA-256 |
|---|---|---|
| `slt_table3.txt` | `2026-09-10T00:55:44.777Z` | `81C5ED08BB3A998982646DAEF5DA36327A888B736D893BF3729070E868331EF0` |
| `slt_table5.txt` | `2026-09-10T00:55:45.025Z` | `391F58CE7B290FDD149658A20A885FF1897D05EB80146F36DEC75A06402E258A` |
| `slt3d_globl.csv` | `2026-09-10T00:55:45.594Z` | `D6B74F0A24E156F86911A383B1A2AE1FDD444017B4875716ED67A0FDEEBA52AE` |

세 파일은 직전 로컬 스냅샷과 내용 및 SHA-256이 같았고, 이번 다운로드 시각만 `manifest.json`에 갱신했다. URL·다운로드 시각·실제 파일 SHA-256 일치 여부는 검증 스크립트가 매번 확인한다.

## 이번 단계에서 완료한 데이터 작업

- 기존의 정상적인 Table 3 우선 연결 정책과 JSON 레코드 튜플 호환성을 유지했다.

- 원본 결측값을 0으로 바꾸지 않으며 Table 3 원본 7,280행을 출력 레코드와 필드별로 대조한다.

- 기존 구현에서 제외되던 Historical 전용 41개 엔터티를 2020년 이전 시계열에 복원했다.
